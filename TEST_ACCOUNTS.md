don't lose track of them. It's plain text on your own computer — **never
commit this file to a public GitHub repo**, and don't put real student data

## Forgot which emails you've already registered?

Log in with any librarian account and go to **Admin → Members** — every
registered email is listed there, along with role and active status.

## Forgot a password?

Use **Forgot password?** on the login screen. This is the same flow every
real app (Facebook, Google, etc.) uses — nobody, including you as the
developer, can retrieve an old password once it's hashed. You always set a
*new* one via the emailed reset link instead.
